Privacy policy

Last updated 14 October 2026. This policy covers Meow Assistant, including the currently live account-independent Google Play edition 2.0.10 (225), the upcoming Play edition 2.0.13 (228) described below, and earlier editions as identified below, package com.meow.meowmba. Publisher contact: dekayrekords@gmail.com.

Play edition 2.0.10 (225): account-independent features

The current Play edition uses the included Basic offline chat model and local workspace features without an account, password, API key, paid subscription or owner-hosted server. Basic gives short text replies and does not execute tools or live lookups. Optional advanced local chat, speech and image models require compatible hardware, storage and explicit downloads. Camera OCR and labels run on device. System speech services may process data under their own provider's policy.

Cloud and LAN AI, Computer/OpenCode, external MCP, authenticated services, authenticated song/place APIs, server media/memory/research/voice, remote MaleCNS and Meta account registration/camera are unavailable in build225 for all users. Saved private connections and encrypted credentials from an older installation are preserved locally on upgrade but cannot enable these disabled functions. Build225 does not contain the Meta wearable SDK.

Account-free public search, web/weather/place/GitHub reads and public model downloads may still use the network. The selected public source receives the query and, where needed for a requested location feature, relevant location; network operators receive connection information such as IP addresses. The included offline model does not make these optional network features or SDK diagnostics offline. User-chosen exports and sharing create separate copies at the destination.

Build225 retains optional Flow notification access after the user's separate disclosure, consent and Android enablement. Notification app identity, title, bounded message text, category and parsed delivery information support local Flow intentions, goal connections, supported road alerts and available media context. Derived goal/context records can persist locally. Disable the feature or revoke notification access to stop future access; this does not automatically erase prior local records. Use supported deletion controls for records you no longer need. Notification processing is distinct from SR16 forwarding, which is excluded from this edition.

Activity and foreground Flow location context remain local inputs to the build225 journal and local conversation pipeline. A saved Ask Meow ring request follows that local pipeline; raw ring input and other apps' screen text are not sent to AI providers. The R08 ring controls, permissions, diagnostic sharing, nonmedical limitations and local retention described below remain applicable. The app is usable when optional permissions are declined.

Upcoming Play edition 2.0.13 (228): optional cloud chat

Play edition 2.0.13 (228) is described here as an upcoming scope and is not represented as released. Its baseline remains account-independent and offline: no Meow account is required, and Basic offline chat remains available without a paid subscription.

In build228, optional cloud chat requires your explicit in-app consent and a provider account or API key that you configure. Meow sends your prompt and included conversation, task or other relevant context to the selected provider over HTTPS. The selected provider receives the request and the configured API key for authentication according to that provider's protocol. Provider retention, training, security and deletion follow the selected provider's policy. OpenRouter defaults to openrouter/free, subject to OpenRouter's availability and account limits. Meow does not automatically choose a paid fallback. Select Basic offline chat to return to local replies. Changing selection affects future requests and does not erase saved credentials or provider copies.

Build228 does not enable LAN/desktop/server integrations, external MCP, autonomous control of other apps, robot actuation, Meta wearable features, SR16 forwarding or SR16 health/display features. Optional R08 controls continue to require the separate disclosure, consent and Android Accessibility enablement described below. A saved Ask Meow ring request follows the selected typed-chat pipeline in build228 and can include the configured request and relevant conversation context; raw ring events and other apps’ screen text are excluded.

The build225 exclusions above remain the historical scope of the currently live edition. Build228's optional cloud chat does not change the raw ring input and other apps' screen-text exclusion from AI requests; those inputs remain excluded unless a user separately supplies related content in a request.

Earlier editions and existing installations

The service descriptions below also cover data practices of older Meow2.0 versions and development editions where external integrations remain available. They do not mean those integrations can be enabled in build225. Users on older versions may still use configured providers; previously shared data remains subject to the recipient's retention and deletion policy. A package-wide Google Play Data safety form covers the applicable distributed versions, rather than only the newest build.

Data stored on your phone

Local records include conversations, memories, notes, workspace files, settings, downloaded models and enrolled speaker profiles. Relevant conversation history, memories or files can become part of a request to a provider you configure. Credentials are stored using the app's encrypted storage. Earlier and development editions can use them to authenticate with their intended service; preserved credentials cannot enable disabled integrations in build225. App data is excluded from automatic Android cloud backup. Files you export or share create separate copies at the destination you choose.

Optional services in earlier or development editions

  • Cloud conversations and connected tasks: your request and relevant history, memories, tool results or documents can be sent to your selected provider or Computer/server endpoint. This can include names, contact details, account identifiers, preferences, drafts, calendar information and app or browsing context that you supply or enable for a task.
  • Speech: a configured cloud transcription service receives recorded speech. Cloud speech output receives the text to speak. The device's system speech service may also process recordings under its provider's policy. Choosing an on-device chat model does not by itself make a separately selected speech service local.
  • Vision: a configured cloud vision service can receive selected images, camera frames or screen captures, with relevant instructions. On-device vision processing remains local, apart from the SDK diagnostics described below.
  • Media generation: the selected service receives prompts and any supported reference inputs. Providers may include Cloudflare Workers AI, AI Horde or a configured image, music or video server. AI Horde community workers receive submitted prompts; anonymous use includes the dataset-sharing disclosure shown in the app. With a personal key, the app requests no dataset sharing, but workers still receive the prompt.
  • Location, navigation, weather and search: enabled features may send a query and relevant approximate or precise location to the selected source. Directions opened in another app are also handled under that app's policy.
  • Downloads and connections: model hosts and connected services receive requests and any authentication needed for them. Network services can receive ordinary connection information, including an IP address. Providers can include OpenAI, OpenRouter, Google Gemini, BigPickle, Hugging Face or a compatible endpoint you enter. Availability depends on your configuration.

These services apply their own policies to retention, security, training and deletion. Selecting a different provider affects future requests and does not erase earlier submissions. Review the selected provider's terms before sending private content. Meow does not sell your personal data or include advertising SDKs.

Included SDKs and diagnostics

Google ML Kit and related Firebase configuration/installation components can collect device and app information, device or installation identifiers, feature events, configuration information, error codes and performance measurements for diagnostics and usage analytics. This is separate from where your AI conversations are processed. See Google's ML Kit data disclosure and Firebase's data disclosure.

Earlier and development editions with the optional Meta wearable integration use Meta's Device Access Toolkit. Meow sets the SDK's analytics opt-out flag. Enabled account/device registration and wearable services are still subject to Meta's privacy policy; the flag does not change the separate Meta companion app's practices.

Meow's support-report action is optional. It includes app/Android version, available memory or thermal status, operating-mode switches and a limited set of process-exit codes/timestamps. It does not include your chat, recordings, credentials or raw logs. Android's share chooser lets you choose its destination. Included SDK diagnostics have separate behavior; this support-report switch does not disable them.

Permissions and controls

Optional Flow location context: after the in-app disclosure and Android permission grant, Meow can record available location and time in the phone’s local context journal and use available context in conversations. The Play edition requests approximate location for Flow and receives optional Flow location only while Meow is visible; it stops when you leave Meow. Availability and precision depend on Android permissions and the location provider. You can decline or revoke access in Android Settings. In earlier or development editions with cloud AI, relevant location or journal context may be included in requests to the selected provider; build225 uses local AI instead.

Microphone, camera and screen capture support features you enable. Fresh setup starts with the microphone off; skipping or denying sensor setup leaves the microphone and camera off. Location supports enabled navigation, road and nearby-place features. Calendar access supports enabled calendar tasks. Bluetooth supports optional accessories. Notification access supports enabled road alerts; notifications provide service and download status. Android photo and document pickers let you select which photos, videos and files Meow imports as local copies. Your originals stay unchanged. Optional usage access supports configured app-management features. You can change feature switches in the app and revoke permissions in Android Settings.

The Play edition does not include autonomous Accessibility control of other apps or physical robot actuation. Permissions alone do not make a cloud feature local: also check the chosen speech, chat and vision providers.

Optional ring controls: after a separate in-app disclosure, your affirmative consent and Android Accessibility enablement, Meowmba Ring Controls uses Android's AccessibilityService API to receive ring key events and access the active app's package, window bounds and control structure. Your configured, verified physical gestures can scroll, move/click the target, navigate, control media and volume, open a chosen app or camera, select a compatible photo shutter, or submit a saved Meow request in allowed foreground apps while the phone is unlocked. Modes and bindings start paused after changes. Controls start paused, and Allow all apps is optional. App control structure, including photo-shutter labels, is processed locally. The ring service does not record screen contents or send screen contents or raw ring input to AI providers. Saved custom requests are stored privately on this phone. If you select Ask Meow, your configured request follows the normal typed-chat pipeline, which is local in build225 and may use the selected AI provider in earlier or development editions, with relevant conversation context; normal task permissions and approvals apply. Avoid saving secrets in ring requests. You can decline, pause, withdraw consent in Smart Ring or disable the service in Android Settings. A diagnostic log is shared only when you use the share action and choose a destination; it includes connection and gesture events, not screen text or sensor readings.

Activity context and smart-ring readings

With user-granted activity-recognition permission, Meow receives Android activity-transition labels such as walking, running, cycling, still and in-vehicle. These labels support Flow’s local journal and conversations; in-vehicle context can adjust update cadence for optional foreground Flow location. Activity transitions can be received while the app is not visible. In earlier or development editions with cloud AI, relevant activity or journal context may be included in requests to the selected provider; build225 uses local AI instead. You can decline or revoke activity-recognition permission in Android Settings.

A compatible R08/QRing Bluetooth ring can provide on-demand battery and step readings and experimental heart rate, oxygen, temperature, HRV and stress sensor tests. Results depend on hardware, firmware, fit and contact. Ring test results are held locally in app memory, are not automatically sent to AI providers and are excluded from shared support diagnostics. General conversation and provider rules above apply to any information you manually supply in a conversation.

Meow Assistant is not a medical device and does not diagnose, treat, cure or prevent medical conditions. Seek advice about medical care from a qualified healthcare professional.

Connections and security

Public API endpoints are required to use HTTPS by the app. Earlier or development editions' SSH connections use SSH encryption. Their user-configured local-network endpoints can use HTTP, which is not encrypted in transit. A universal claim that every connection is encrypted would therefore be incorrect. The destination's operator controls how it stores and handles data it receives.

Retention and deletion

Delete supported local conversations and records using the app's controls. Clearing app storage or uninstalling removes its local data, credentials and downloaded assets. Preserve anything you need before doing so. Exported, shared or manually copied files must be removed separately from their destinations.

Removing local data does not delete information already sent to an AI provider, SDK operator, connected server or sharing destination. Request deletion from the relevant provider or destination administrator under its policy. Meow does not offer a single mechanism that deletes all third-party copies, and does not promise automatic deletion within a fixed period.

Children

Meow Assistant is not directed at children under 13.
